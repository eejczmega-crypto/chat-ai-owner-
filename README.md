# Chat MeGa AI — Owner Edition

مشروع Node.js مستقل بواجهة عربية RTL. يحتوي على تسجيل حسابات، جلسات دخول، محادثات AI، ولوحة مالك محمية.

## التشغيل
1. استخدم Node.js 20 أو أحدث.
2. انسخ `.env.example` إلى `.env`.
3. ضع `OPENAI_API_KEY`، وحدد `OWNER_EMAIL` و`OWNER_PASSWORD` و`SESSION_SECRET` بقيم قوية.
4. نفّذ `npm install` ثم `npm start`.
5. افتح `http://localhost:3000`.

## صلاحيات المالك
- حساب المالك يُنشأ تلقائياً عند أول تشغيل من بيانات البيئة.
- المالك يحصل على Lifetime واستخدام غير محدود.
- لوحة المالك: `/admin` (تتطلب تسجيل دخول المالك).
- عرض المستخدمين، حظر/إلغاء حظر، تغيير خطة المستخدم، تعديل اسم الموقع، حد الرسائل، ووضع الصيانة.
- كل عمليات الإدارة والتحقق من الصلاحيات تتم على الخادم.

## النشر
انشره على استضافة Node.js تدعم تخزيناً دائماً للملفات أو استبدل طبقة JSON بقاعدة بيانات مُدارة قبل الاستخدام العام واسع النطاق. لا تضع أسرار API في ملفات الواجهة. فعّل HTTPS، والنسخ الاحتياطية، وسياسة الخصوصية وشروط الاستخدام. لا ترفع `.env` أو مجلد `data/` إلى GitHub.

## حدود النسخة
توليد الصور، البحث المباشر، رفع الملفات وتحليلها، والصوت غير مفعّلة في هذا الإصدار. اشتراك Premium المعروض تجريبي ولا يتحقق من التحويلات تلقائياً.


## إعداد حساب المالك
- البريد الافتراضي للمالك مضبوط على `mr11mega@gmail.com` في `.env.example`.
- انسخ `.env.example` إلى `.env` على جهازك أو اضبط المتغيرات في لوحة استضافة Node.js.
- عيّن `OWNER_PASSWORD` إلى كلمة مرور جديدة وفريدة لا تقل عن 12 حرفاً. لا تستخدم كلمة المرور التي أُرسلت في المحادثة لأنها أصبحت مكشوفة.
- عيّن `SESSION_SECRET` إلى قيمة عشوائية طويلة لا تقل عن 32 حرفاً.
- أضف مفتاح OpenAI في `OPENAI_API_KEY` لتفعيل المحادثة الذكية.
- بعد التشغيل، سجّل الدخول بالبريد وكلمة المرور اللذين ضبطتهما، ثم افتح `/admin` للوصول إلى لوحة المالك.

**تنبيه أمني:** لا ترفع ملف `.env` إلى GitHub ولا ترسله لأحد. ملف `.env.example` لا يحتوي على كلمة مرور فعلية.
